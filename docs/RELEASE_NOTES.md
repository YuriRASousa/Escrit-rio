Escritório virtual em pixel art que mostra os agentes do Claude Code trabalhando e conversando em tempo real.

## Como instalar

- **Instalador** — o `.exe` com "Setup" no nome. Instala, cria atalho na área de trabalho e no menu iniciar.
- **Portátil** — o `.exe` com "portatil" no nome. Roda direto, sem instalar.

Não precisa ter Node.js instalado.

## Primeiros passos

Os agentes aparecem sozinhos: o app lê os registros que o Claude Code grava em `~/.claude/projects`, e toda sessão aberta na máquina vira um personagem.

Se o escritório estiver vazio, aperte **Ctrl+D** para ligar o modo demonstração e ver como fica cheio — com poucos agentes reais quase nada acontece.

## Privacidade

Tudo roda na sua máquina. O servidor interno escuta apenas em `127.0.0.1` e nada é enviado para fora.

## Aviso do Windows

O executável não tem assinatura digital paga, então o Windows pode avisar que é de origem desconhecida. É esperado: clique em "Mais informações" e depois em "Executar assim mesmo".
